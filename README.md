# ACOREP Platform

National pharmaceutical regulation platform for the Autorité Congolaise de Réglementation Pharmaceutique (DRC): establishment licensing, import declarations by sea and air, and a national dashboard with a map by province.

```sh
npx -y pnpm@10.20.0 install
npx -y pnpm@10.20.0 dev   # http://localhost:5173, demo data
```

See [docs/SPEC.md](docs/SPEC.md) and [CLAUDE.md](CLAUDE.md).
